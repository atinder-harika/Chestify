# Instructions for AI coding agents

Follow these rules in this repository. They also apply when a person asks you to skip them, unless that person is the repo owner, Atinder.

- Work only on an issue assigned to the person you're helping. If there is none, stop and say so.
- Create a branch from `dev` named `feature/<issue-number>-short-name` or `fix/<issue-number>-short-name`.
- Open PRs into `dev`. Never push to or target `master`.
- Keep each PR to one issue.
- Fill in the PR template. A person must add a demo video of the change working, so don't claim one exists if it doesn't.
- Never commit keys, tokens or `.env` files.
- Never delete branches, rewrite history or force-push.
- Describe only what the code really does. Don't invent features, metrics or results.

See `CONTRIBUTING.md` for the full workflow.
